# 情绪稳定 Offline Ledger

在线地址：https://17530378798.github.io/account-book/

这是一个纯前端、可离线使用的个人记账 PWA。数据保存在当前设备的浏览器中，打开应用会直接进入“我的账本”，不需要登录密码。

## iPhone 使用

1. 使用 Safari 打开在线地址。
2. 点击 Safari 底部的分享按钮。
3. 选择“添加到主屏幕”。
4. 首次联网打开并加载完成后，之后可离线使用。

不同设备的数据不会自动同步。换手机或清除 Safari 网站数据前，请先使用“导出备份”保存数据。

“备份与恢复”支持 CSV 和 JSON：CSV 可用 Excel 或 Numbers 打开和编辑，JSON 会完整保存记录、分类预算与最近删除。导入时可选择合并或替换当前账本。

应用更新沿用原来的本地数据位置，无需重新添加到主屏幕。每次保存会尝试写入本机备用副本；主副本缺失或损坏时自动读取备用副本。如果两份均无法读取，会停止写入并提示，避免覆盖原数据。备用副本仍属于当前浏览器的网站数据，不能防止清除网站数据、设备损坏或换机带来的丢失，请定期导出 JSON 到“文件”或 iCloud。

外观提供八种主题。手机上的外观和最近删除窗口全屏显示，内容独立滚动，适配安全区域及横屏；底部导航独立固定，切换页面时回到内容顶部。
